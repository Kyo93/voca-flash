# Proposal: Import Refactor — Context-Aware Vocabulary Import
Generated by: cm-brainstorm-idea + cm-planning
Date: 2026-04-15

---

## Why we're doing this

### Qualified Problem
Topic model now requires `roadmap_id` (NOT NULL). ImportWordsModal auto-creates topics with `roadmap_id: roadmapId ?? null`, causing:
- **Orphan topics** when `roadmapId` is undefined (null in DB = orphan)
- **Wrong roadmap pollution**: Topics accidentally land in "300 từ tiếng Anh cơ bản" (first/active roadmap by default)
- **Duplicate slug** generation — no uniqueness check on slug field

### 9 Windows Summary
- **Past → Present:** Topics were free-floating; import auto-created them freely. Now Topic MUST belong to a Roadmap.
- **System tension:** Import logic still assumes old model (free-floating topic) — needs to align with new model constraint.
- **Future:** Import must respect Roadmap context; only logical place is RoadmapSetupPage.

### Root Causes
1. **Tech:** `roadmap_id: roadmapId ?? null` → null when prop is undefined → orphan/accidental topic
2. **Product:** No guard preventing import without Roadmap context
3. **Design:** Import button exists in WordsPage (no guaranteed roadmap context) AND RoadmapSetupPage (has context)

---

## What's changing

### Options Evaluated
- **Option A** (No Auto-Create): Remove auto-create entirely, admin must pre-create topics. 2-step workflow. Effort S.
- **Option B** (Guard + Context-Aware) ✓ RECOMMENDED: Import only works within Roadmap context; auto-create respects Roadmap. Single workflow. Effort M.
- **Option C** (Inline Roadmap selector): Add dropdown inside modal. Most flexible but effort L, adds confusion about source-of-truth.

### Recommendation: **Option B**
Guard + Context-Aware Auto-Create:
1. Remove import button from WordsPage
2. Keep import button in RoadmapSetupPage (has guaranteed `roadmapId` context)
3. Add guard: if `!roadmapId` → show warning UI, no upload
4. Auto-create topic: always set `roadmap_id = roadmapId`
5. Slug uniqueness: append `-1`, `-2` if duplicate slug exists
6. Show "Đang nhập vào: [RoadmapName]" label from step 1
