# Design: Mobile Mastery Archive Redesign
Generated by: cm-planning
Date: 2026-06-30

## Context & Technical Approach

The current mobile Mastery screen tries to be a dashboard, a filter panel, and a word archive at the same time. User review identified six concrete issues:

- The "LEXICAL ARCHIVE" eyebrow has no user value.
- The subtitle is too long for mobile scanning.
- The stat block consumes too much vertical space.
- Filter controls consume too much space.
- Word cards are large but sparse.
- The mobile word detail sheet shows much less useful information than desktop/notebook surfaces.

Recommendation from the brainstorming pass: implement Option B, a mobile-specific archive redesign. The screen should become a fast vocabulary lookup and review surface, not a miniature dashboard.

### Assumptions

- Verified: canonical mobile viewport is S25 Ultra `390x850` CSS px.
- Verified: `MobileMasteryView` owns the current mobile list, filters, card, and bottom detail sheet.
- Verified: desktop `WordDetailPanel` has a richer information structure: overview, linguistic, notes, stats.
- Verified: `MasteryWord` currently does not include all word fields available in the core `Word` model, such as `pos`, `example_vi`, `synonyms`, `antonyms`, and `word_family`.
- Needs implementation decision: enrich `MasteryWord` payload directly, or load extended detail on demand when a word sheet opens. This plan chooses on-demand detail enrichment first to reduce list payload risk.

## Proposed Changes

### `src/components/mobile/MobileMasteryView.tsx`

Redesign the mobile shell into a compact archive:

- Remove the eyebrow text entirely.
- Replace the long subtitle with a compact summary such as `57 từ · 7 đến hạn`.
- Keep the notebook count as a small action chip in the header.
- Keep search prominent, but reduce height and spacing.
- Replace the four stat cards with a single compact metric strip.
- Replace the two-row filter grid and full-width filter button with:
  - one horizontal segmented control: `Tất cả`, `Đến hạn`, `Yếu`, `Đã thuộc`;
  - one compact icon filter button for advanced filters;
  - an active-filter summary chip only when advanced filters are active.
- Redesign word cards as compact list rows:
  - word + phonetic + definition;
  - topic/due/stability metadata in one line;
  - notebook and selection controls remain 44px touch targets;
  - the card should fit about 2.5 to 3 visible rows in a 390x850 viewport after header/filter.
- Increase bottom padding so the last card is never hidden behind bottom navigation.

### Mobile Detail Sheet

Replace the current short detail sheet with a richer mobile word dossier:

- Sheet header: word, phonetic, topic, notebook action, close action, audio action if available.
- Tabs: `Tổng quan`, `Ngôn ngữ`, `Ghi chú`, `Thống kê`.
- Overview tab:
  - definition;
  - example;
  - Vietnamese example if available;
  - image if available.
- Linguistic tab:
  - POS if available;
  - word family;
  - synonyms;
  - antonyms;
  - fallback empty states when fields are missing.
- Notes tab:
  - existing note display;
  - edit/save/cancel flow with the existing `onSaveNote` contract.
- Stats tab:
  - stability, difficulty, reps, lapses;
  - next review date;
  - due/mastered state.

### Data Strategy

Use on-demand enrichment for detail:

- Keep the list query light for performance.
- Add a detail loader keyed by `word_id` when opening the sheet.
- Source candidates:
  - existing `words` table fields through a new storage helper;
  - notebook word entry fields where available;
  - fallback to the existing `MasteryWord` values while loading or if enrichment fails.
- Add an explicit type, e.g. `MasteryWordDetail = MasteryWord & Partial<Pick<Word, 'pos' | 'difficulty' | 'example_vi' | 'synonyms' | 'antonyms' | 'word_family' | 'image_position'>>`.

This avoids blocking the archive redesign on a Supabase RPC migration while still enabling richer detail.

### Tests

Update `tests/unit/MobileMasteryView.test.tsx` to assert:

- no `LEXICAL ARCHIVE` text renders on mobile;
- compact summary renders;

- filters are a compact segmented control plus icon button;

### Visual QA

Required viewport: `390x850`.

Verify:

- no horizontal overflow;
- bottom nav does not cover list content;
- at least two full word rows are visible after header/filter at typical scroll top;
- detail sheet is scrollable and reachable with one thumb;
- controls remain at least 44px tall;
- text does not overlap in Vietnamese.

- Desktop Mastery redesign.
- Notebook book-spread redesign.
- Changing the FSRS algorithm.
- Reworking Supabase RPCs unless on-demand detail proves too slow or incomplete.
- Adding new vocabulary fields that do not already exist in the data model.
