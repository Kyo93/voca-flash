# Proposal: 3D Character Unlock Showcase
Generated by: cm-brainstorm-idea
Date: 2026-04-25

## Why we're doing this
VocaFlash now has a working EXP and badge foundation. The next retention layer can turn EXP into visible identity: learners unlock collectible 3D characters and display one on the Dashboard.

## Qualified Problem
For vocabulary learners who return daily, the current reward system shows progress but does not yet give them a personal, visible representation of achievement. The product needs a collectible layer that makes earned EXP feel owned without damaging level progression.

### Root Causes
1. EXP is currently lifetime progress, not a spendable wallet.
2. Dashboard has progress cards but no personal showcase slot.
3. Existing badge/level rewards are abstract; characters can make progress more emotionally memorable.

### Impact if not addressed
- EXP remains useful but less motivating after initial milestones.
- Dashboard misses a strong personalization loop.
- Future reward systems may fragment if spending is bolted directly onto total XP.

## Options Evaluated
### Option A: Threshold Characters
Unlock characters automatically when lifetime XP reaches thresholds.

**Effort:** S  
**Risk:** Low  
**Pros:** No wallet complexity, no spending confusion, quick to build.  
**Cons:** User does not feel like they actively “buy/unlock”; less agency.

### Option B: Spendable EXP Wallet
Keep lifetime XP for levels, add spendable XP balance for character unlocks.

**Effort:** M  
**Risk:** Medium  
**Pros:** Matches user intent, gives meaningful choices, extensible economy.  
**Cons:** Requires DB migration, wallet math, unlock transaction safety.

### Option C: Full 3D Room / Gallery
Build a 3D scene where unlocked characters stand in a display room.

**Effort:** L/XL  
**Risk:** High  
**Pros:** Strong visual impact and long-term differentiation.  
**Cons:** Requires Three.js, 3D assets, performance work, mobile validation.

## Recommendation
Choose Option B as the product model, implemented with a controlled visual scope:

1. Add a spendable EXP balance derived from earned XP minus spent XP.
2. Add a character catalog with costs, rarity, i18n labels, and 3D/3D-style assets.
3. Add a character unlock page/modal and a Dashboard showcase card.
4. Start with 3D-style rendered character assets or lightweight GLB previews; only expand to a full Three.js room after the economy proves useful.
