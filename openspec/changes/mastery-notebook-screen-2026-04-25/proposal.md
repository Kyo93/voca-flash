# Proposal: Mastery Notebook Screen
Generated by: cm-brainstorm-idea
Date: 2026-04-25

## Why we're doing this

### Qualified Problem
For VocaFlash learners who save vocabulary with the heart action, the current notebook state is distributed across row icons and the word detail note tab. The product already stores notebook entries and rich notes, but Mastery does not provide a dedicated saved-word workspace where learners can review only the words they intentionally collected.

Root causes:
- Technical: `user_notebook_entries` stores saved words, but the UI has no screen that fetches notebook entries with full word details.
- Product: hearting a word feels like a bookmark, yet there is no bookmark destination.
- Design: note editing exists in a detail drawer, but users cannot personalize how the saved-word collection is displayed.

Impact if not addressed:
- The heart action remains low-value because saved words are hard to revisit as a set.
- Personal notes are less discoverable.
- Mastery becomes a ledger, not a study workspace.

## What's changing

### Options Evaluated

#### Option A: Header Overlay Notebook
Add a notebook icon to the Mastery header. Clicking it opens a full-screen overlay with saved words, notes, search, and style controls.

Effort: M. Risk: Low.

#### Option B: New `/notebook` Route
Add a standalone route and sidebar item for the notebook.

Effort: M-L. Risk: Medium due navigation and layout scope.

#### Option C: Expand Existing Detail Drawer
Keep the experience inside the existing word detail side panel.

Effort: S. Risk: Medium product risk because it does not create the requested notebook screen.

### Recommendation
Choose Option A: Header Overlay Notebook.

Why:
1. It directly matches the request: a notebook icon on Mastery that opens a notebook-like screen.
2. It respects the current architecture: Mastery already owns saved-word state and detail interactions.
3. It avoids route/sidebar scope while still creating a substantial, personalized workspace.
