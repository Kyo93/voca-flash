## Context & Technical Approach

### Core Loop
```
Study action (rate a card)
  → Earn XP (5/10/15/20/50 based on rating)
  → XP accumulates in wallet (total_earned_xp in user_profiles)
  → When milestone condition met → character type assigned to next available slot
  → User can invest wallet XP into any character → character level increases
  → Level 5 = special animation reveal
```

### Why XP in `user_profiles` (not separate table)
- Matches existing VocaFlash architecture: `user_profiles` already holds user-level stats
- Single source of truth for XP balance
- Available XP = `total_earned_xp - sum(invested_xp across all user_characters)`
- Avoids extra join for balance calculation

### Slot Logic (1 slot/month, max 5)
```
monthsActive = floor(monthsSinceAccountCreation)
availableSlots = min(monthsActive, 5)
assignedSlots = count(user_characters WHERE user_id = X)
canUnlockNewSlot = assignedSlots < availableSlots
```
Character type waits in "pending inventory" if slot not yet available.

### Level Derivation (pure client-side, no stored level column)
```
invested_xp → level (deterministic)
  0-199   → Level 1
  200-499 → Level 2
  500-999 → Level 3
  1000-1999 → Level 4
  2000+   → Level 5 (MAX)
```
Computed inline — no `level` column in DB (avoids sync bugs).

### Milestone Trigger
- Check at end of each study session (in `handleSessionComplete` inside `useFlashcard`)
- Fetch `user_achievements` for already-achieved milestones
- For each unmet milestone, evaluate condition client-side using current progress data
- If newly achieved → call `unlockCharacter()` RPC

## API Contracts (Supabase RPC)

### `check_and_unlock_milestone(p_user_id UUID)`
```sql
RETURNS JSONB — { unlocked: BOOLEAN, character_type: TEXT, milestone_id: TEXT }
```
Logic:
1. Fetch `user_achievements` for user
2. For each unmet milestone, evaluate condition (streak from `user_profiles`, mastered count from `user_srs_records`)
3. Return first newly-unlocked milestone (if any), or `{unlocked: false}`
4. If unlocked: INSERT INTO `user_characters` (if slot available) or INSERT INTO `user_character_pending` (if slot full)
5. INSERT INTO `user_achievements`

### `invest_character_xp(p_user_id UUID, p_character_id UUID, p_amount INTEGER)`
```sql
RETURNS JSONB — { success: BOOLEAN, new_invested_xp: INTEGER, new_level: INTEGER }
```
Logic:
1. Check `user_profiles.total_earned_xp >= p_amount`
2. Update `user_characters SET invested_xp = invested_xp + p_amount WHERE id = p_character_id`
3. Update `user_profiles SET total_earned_xp = total_earned_xp - p_amount`
4. Return new totals + new level (computed from new invested_xp)

### `add_session_xp(p_user_id UUID, p_amount INTEGER)`
```sql
RETURNS void
```
Called by client after each session. Updates `user_profiles.total_earned_xp += p_amount`.

## Milestone Evaluation (client-side conditions)

```typescript
const MILESTONE_DEFINITIONS: MilestoneDefinition[] = [
  { id: 'streak_7',         type: 'streak',       threshold: 7,  characterType: 'seedling' },
  { id: 'words_10_mastered', type: 'mastered',    threshold: 10, characterType: 'spider' },
  { id: 'words_30_mastered', type: 'mastered',    threshold: 30, characterType: 'butterfly' },
  { id: 'words_50_mastered', type: 'mastered',    threshold: 50, characterType: 'tree_boy' },
  { id: 'roadmap_complete_1', type: 'roadmap',   threshold: 1,  characterType: 'farmer' },
  { id: 'words_100_mastered', type: 'mastered',   threshold: 100, characterType: 'mini_dragon' },
  { id: 'streak_30',         type: 'streak',       threshold: 30, characterType: 'bonsai' },
  { id: 'words_500_mastered', type: 'mastered',   threshold: 500, characterType: 'golden_dragon' },
]
```

Condition evaluation reads from `user_profiles.streak_days` and `user_srs_records` count WHERE `mastered = true`.

| Feature | Verification Method |
|---|---|
| XP wallet increments after study | Manual: rate 3 cards, check `user_profiles.total_earned_xp` |
| Character unlocks on milestone | Mock `user_profiles.streak_days = 7`, call RPC, check `user_characters` INSERT |
| Level increases on XP invest | Invest 200 XP, check `invested_xp` = 200, level derived = 2 |
| Shelf renders 5 slots | Visual: open RightSidebar, see 5 slot boxes |
| Locked slot shows requirement | Visual: new user sees 5 locked slots |
| Unlock popup appears | Complete session with milestone trigger condition met |
| Character idle animation | Visual: character bounces/wiggles continuously |
| XP spent deducts wallet | Check `total_earned_xp` decreases, sum `invested_xp` increases |
