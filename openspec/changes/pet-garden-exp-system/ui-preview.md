### Level-up mechanic (concept)
```
XP invested into character → level increases
Level 1: 0 XP invested
Level 2: 200 XP invested
Level 3: 500 XP invested
Level 4: 1000 XP invested
Level 5 (MAX): 2000 XP invested → character gets special animation

Note: XP invested = separate from XP source (study actions)
User CHOOSES to spend XP on a character after earning it
```

### Cameo States

| State | Visual | Trigger |
|---|---|---|
| Idle | 🕷️ bouncing slowly (CSS loop, 2s) | Always visible when studying |
| Correct | +10 XP floats up, cameo does jump | rating ≥ 3 |
| Wrong | cameo shows 😟 briefly | rating = 1 (Again) |
| Level up | ✨ sparkle burst, cameo grows 120% then back | character reaches new level |
| Session complete | 🎉 full celebration, cameo spins | last card in session |
