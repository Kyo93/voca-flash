## Why we're doing this

### Qualified Problem (Updated)

**For:** VocaFlash users who want tangible, collectible proof of their learning milestones.
**Who:** Language learners feel their progress evaporates after each session — the flashcard flips back and there's nothing to show for it.
**The:** Study experience is a **one-way stream** — words go in, reviews get scheduled, but nothing materializes in the user's personal space inside the app.
**That:** Users need **trophy-like unlocks** — characters that prove they hit a milestone and can be displayed as proof of effort.
**Unlike:** Animal Crossing (milestone → furniture/fish/bug collection), Stardew Valley (skill XP → tools/upgrades), or Pokemon (badge → gym badge display) — but for vocabulary learning.
**Our approach:** Milestones = farming actions; characters = collectible rewards displayed on a shelf in the app.

### Root Causes
1. **Product:** No "collection loop" — Duolingo's streak shield is binary (on/off), Animal Crossing's furniture collection is deep. VocaFlash has nothing between "you studied today" and "nothing happened."
2. **Design:** Sidebar space is empty real estate — perfect for a character shelf display.
3. **Tech:** No milestone definition engine, no character reward system, no collectible display UI.

## What's changing

### Options Evaluated

#### Option A — Farm-Garden Milestone Collection 🏆 *(RECOMMENDED)*
**Approach:** Học từ = "canh tác". Mỗi mốc học tập (10 từ mới, 50 từ đã mastered, 7-day streak, 30-day streak, hoàn thành roadmap) tưới cho cây → **hoa nở, quả chín**. Khi milestone hoàn thành → **nhận được 1 nhân vật hoạt hình** để trưng bày trên shelf. Gameplay giống Stardew Valley / Animal Crossing — nhưng "crop" là từ vựng.

**Effort:** M (~2-3 tuần)

#### Option B — Achievement Badge → Character Unlock
**Approach:** Mỗi achievement (streak 7/30/100, words learned, topics completed) khi đạt → hiện **character unlock popup** với animation fanfare. Character sau đó vào shelf. Giống Pokemon badge hơn — achievement-driven, character là reward.

**Effort:** S (~1 tuần)
**Risk:** Low — simpler than Option A, but less "world-building" feel

#### Option C — Collection Ecosystem (Option A + Option B + Seasons)
**Approach:** Option A nhưng thêm **seasonal characters** — mỗi quý có bộ reward mới, collection có tính khan hiếm. Giống Animal Crossing seasonal events.

**Effort:** L (~4-6 tuần)
**Risk:** High — seasons require content pipeline, backend season management, UI for "limited time" warnings

## 🎯 Recommendation

**Choose Option A — Farm-Garden Milestone Collection**

### Why Option A:
1. **Metaphor matches perfectly** — "Canh tác từ vựng" = watering plants with daily study. Hoa nở, cây lớn = words mastered, milestone reached. Không có gì artificial.
2. **Collection loop is addictive** — Hoàn thành 7-day streak → nhận seedling. 30 từ mastered → nhận butterfly. Mỗi character là proof of effort + reason to continue.
3. **Shelf display là "room"** — 2 bên màn hình study trở thành character shelf, giống Animal Crossing museum / Pokemon PC box. Đẹp, personal, có animation.
4. **Có thể mở rộng tự nhiên** sang Option C (seasonal characters) khi đã có v1.

### Why NOT Option B:
- Badge-to-character cảm giác như "bạn đạt thành tích" — đúng nhưng thiếu sự khám phá. Farm collection có chiều sâu hơn.

### Why NOT Option C:
- Quá nhiều cho v1. Content pipeline là áp lực. Hãy ship farm có sẵn, prove retention lift, rồi mới add seasons.

### Quick-win v1.0 scope (suggested phasing):
1. **v1.0:** 5 milestones → 5 characters, static shelf display, milestone unlock popup
2. **v1.1:** Plant growth animation (hạt → cây → hoa), shelf becomes 3D-ish display
3. **v1.2:** Character naming, shelf customization (background shelf theme)

## Technical Decisions (Proposed)

### XP Source (unchanged from previous)
- Rating: Again=5 XP, Hard=10 XP, Good=15 XP, Easy=20 XP
- Mastery bonus: +50 XP when word transitions New→Review
- XP accumulates toward milestone thresholds (not toward character "feeding")

### Milestone → Character Reward System (8 characters total, 5 slots max)
| Milestone ID | Condition | Character Reward | Slot Order |
|---|---|---|---|
| `streak_7` | 7-day streak | Seedling | Month 1 |
| `words_10_mastered` | 10 words mastered | Tiny Spider | Month 2 |
| `words_30_mastered` | 30 words mastered | Butterfly | Month 3 |
| `words_50_mastered` | 50 words mastered | Tree Boy | Month 4 |
| `roadmap_complete_1` | 1st roadmap done | Farmer | Month 5 |
| `words_100_mastered` | 100 words mastered | Mini Dragon | Month 6 |
| `streak_30` | 30-day streak | Red Bonsai | Month 7 |
| `words_500_mastered` | 500 words mastered | Golden Dragon | Month 8+ |

**Slot unlock rule:** User nhận slot mới mỗi tháng bất kể milestone. Milestone trigger chỉ quyết định **character type** nào được gán vào slot. Nếu milestone đạt sớm → character chờ trong "inventory" cho đến khi slot mở.

### DB Schema (updated with level system + slot limit)
```sql
-- Milestone definitions (static reference)
CREATE TABLE milestones (
  id             TEXT PRIMARY KEY,
  name_vi        TEXT NOT NULL,
  name_en        TEXT NOT NULL,
  description    TEXT,
  character_type TEXT NOT NULL,
  unlock_order   INTEGER NOT NULL  -- 1-8, determines slot assignment order
);

-- User's unlocked characters (max 5 per user at a time)
CREATE TABLE user_characters (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id         UUID REFERENCES auth.users(id) ON DELETE CASCADE,
  character_type  TEXT NOT NULL,
  unlocked_at     TIMESTAMPTZ DEFAULT now(),
  display_order   INTEGER DEFAULT 0,
  invested_xp     INTEGER DEFAULT 0,  -- XP invested into this character
  level           INTEGER DEFAULT 1,   -- 1-5, derived from invested_xp
  acquired_from   TEXT,                -- milestone_id that unlocked this
  UNIQUE(user_id, character_type)
);

-- Achievement tracking (for counting milestones)
CREATE TABLE user_achievements (
  user_id      UUID REFERENCES auth.users(id) ON DELETE CASCADE,
  milestone_id TEXT REFERENCES milestones(id),
  achieved_at  TIMESTAMPTZ DEFAULT now(),
  PRIMARY KEY (user_id, milestone_id)
);

-- User XP wallet (separate from invested XP)
CREATE TABLE user_xp_wallet (
  user_id       UUID PRIMARY KEY REFERENCES auth.users(id) ON DELETE CASCADE,
  total_earned  INTEGER DEFAULT 0,
  total_spent  INTEGER DEFAULT 0,
  updated_at    TIMESTAMPTZ DEFAULT now()
);
-- Balance = total_earned - total_spent
```

### Character State (TypeScript)
```typescript
interface UserCharacter {
  id: string
  characterType: CharacterType  // 'seedling' | 'spider' | 'butterfly' | 'tree_boy' | 'mini_dragon' | 'farmer' | 'bonsai' | 'golden_dragon'
  unlockedAt: Date
  investedXp: number    // XP user invested into this character
  level: number        // 1-5, derived: 0→Lv1, 200→Lv2, 500→Lv3, 1000→Lv4, 2000→Lv5
  acquiredFrom: string  // milestone_id
}

type CharacterType =
  | 'seedling' | 'spider' | 'butterfly' | 'tree_boy'
  | 'mini_dragon' | 'farmer' | 'bonsai' | 'golden_dragon'

const LEVEL_THRESHOLDS = [0, 200, 500, 1000, 2000]  // invested XP → level

function getLevel(investedXp: number): number {
  for (let i = LEVEL_THRESHOLDS.length - 1; i >= 0; i--) {
    if (investedXp >= LEVEL_THRESHOLDS[i]) return i + 1
  }
  return 1
}
```

## Open Questions — ANSWERED

1. **Character inventory limit?** → Max **5 slot**, unlock 1 slot mới mỗi tháng (1 slot/month)
2. **Character có level/stage không?** → **CÓ** — mỗi character có 5 level. User đầu tư XP vào character để level up.
3. **Milestone có bị reset không?** → **KHÔNG** — achievement giữ mãi mãi, không revoke khi streak gãy
4. **Character có thể bán/trade không?** → **KHÔNG** — trophy cá nhân, không có economy

### Level-up mechanic (confirmed)
```
XP earned from study actions (Again=5, Hard=10, Good=15, Easy=20, Mastery=+50)
→ User CHOOSES to invest XP into a character → character levels up

Level thresholds:
  Level 1: 0 XP invested
  Level 2: 200 XP invested
  Level 3: 500 XP invested
  Level 4: 1000 XP invested
  Level 5 (MAX): 2000 XP invested → special golden animation

Note: Invested XP is separate from source XP. It's a deliberate "feed your character" action.
```
