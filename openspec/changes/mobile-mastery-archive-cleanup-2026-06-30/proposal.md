# Proposal: Mobile Mastery Archive Cleanup
Generated by: cm-start
Date: 2026-06-30

## Why
The mobile Archive/Kho từ screen still feels like the old dashboard: big stat cards, large filter blocks, and visible checkboxes consume too much vertical and horizontal space on the S25 Ultra viewport.

## What Changes
- Archive becomes a lookup shelf, not a second dashboard.
- Remove the four large stat cards from Archive.
- Add a compact archive summary line under search.
- Convert primary filters into a horizontal chip row.
- Move selection into an explicit selection mode so checkboxes are hidden by default.
- Make word rows denser while preserving 44px touch targets.

## Constraints
- Mobile target: 390x850 CSS px.
- Preserve Inbox and Word Dossier behavior.
- Preserve existing filter/search/data contracts.
- Use i18n keys for all new visible text.
